# Source snapshot

This repository publishes a release snapshot of Friend's Fridge for review.
Its initial snapshot commit records the publisher, not exclusive authorship
of every included file. The snapshot includes pre-existing source whose
development history remains in the [source repository](https://github.com/cccuirq/FriendsFridge).

Existing image source, author, and license metadata are retained in the asset
manifests and credits. Agent assistance and verification are described in
`deepspace-app/SUBMISSION.md`.

The application files match the deployed DeepSpace source identified by
`release/deepspace.json`; replacing GitHub review history does not change the
application or its deployment authority.
